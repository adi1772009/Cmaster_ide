-- Standard I/O and File Handling (<stdio.h>) --
34. Read formatted student records from a text file, compute averages, and write to an output file.
35. Perform binary file reading and writing of struct arrays using fread and fwrite.

-- Memory Management & Utilities (<stdlib.h>, <stddef.h>) --
37. Allocate dynamic multi-dimensional arrays using malloc, calloc, realloc, and properly deallocate with free.
38. Implement generic sorting using standard qsort with custom struct comparison callbacks.
39. Implement dynamic binary search using standard bsearch function.

-- String & Memory Manipulation (<string.h>, <wchar.h>) --
40. String tokenization and parsing using strtok and strsep.
41. Low-level memory block manipulation using memcpy, memmove, memset, and memcmp.
42. Wide character string processing using wchar_t and wprintf.

-- Mathematical & Complex Computations (<math.h>, <complex.h>, <tgmath.h>) --
43. Compute trigonometric, logarithmic, exponential, and power functions with error checks.
44. Perform arithmetic calculations on complex numbers using double _Complex types.

-- Bitwise Operations & Byte Representation (<stdbit.h>, <stdint.h>) --
45. Standard fixed-width integer operations (uint8_t, int64_t) with bitwise rotations and masking.
46. Count leading zeros, trailing zeros, and bit population count using C23 <stdbit.h> features.
47. Safe integer arithmetic overflow detection using C23 <stdckdint.h> macros (ckd_add, ckd_mul).

-- Low-Level Control Flow & Signal Handling (<setjmp.h>, <signal.h>) --
48. Implement error recovery mechanism across deep function calls using setjmp and longjmp.
49. Register custom signal handlers for SIGINT and SIGFPE to capture user interrupts and divide-by-zero.

-- Multi-Threading & Synchronization (<threads.h>, <stdatomic.h>) --
50. Multi-threaded matrix multiplication using C11 threads (thrd_create, thrd_join).
51. Thread synchronization using mutexes (mtx_lock, mtx_unlock) and condition variables.
52. Lock-free counter implementation using atomic variables and memory ordering directives.

-- Time, Date & Benchmarking (<time.h>) --
53. High-resolution execution timing of algorithm performance using clock_gettime / timespec_get.
54. Calendar date-time formatting and conversion using time_t, struct tm, and strftime.

-- Diagnostics & Assertions (<assert.h>, <errno.h>) --
55. Runtime verification testing using assert macro and static assertions using static_assert.
56. System error logging using errno, perror, and strerror.
